🤖 大腦對話模式 (Dialogue Mode)

主宰貓咪平常聊天時的聰明度。使用雲端大腦能讓本喵更有同理心、更會傲嬌安慰主人喔！

🧭 意圖辨識模式 (Intent Routing Mode)

主宰貓咪理解主人指令（如上網查詢、拍照分析等）時的判斷方式。建議選擇 ⚡ Local 邊緣運算，能省下雲端 API 額度並使反應更為敏捷！

☁️ 雲端模型設定 (Cloud Model Settings)

設定大腦對話、意圖辨識或搜尋改寫在使用「雲端」模式時的 API 模型與推理參數。

👤 稱呼與助理設定 (Personalization)

設定對話稱呼、語速自適應以及語音辨識的核心參數。

📍 定位與在地化設定 (Location & Localization)

設定物理位置。這能讓本喵更精準辨識在地景點（如「圓山」）、自動為天氣與景點搜尋補上地區前綴！
